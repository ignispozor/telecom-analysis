# Telecom-analysis

## Objetivo del proyecto

Como analista de datos, el objetivo del proyecto de Telecomunicaciones para la empresa ConnectaTel es evaluar el comportamiento de sus clientes, observar sus patrones de consumo, identificar segmentos de usuarios con el fin de sugerir mejoras en sus servicios u optimizarlos.

## Datasets Utilizados

Los archivos utilizados para el análisis son los datasets:

- usage.csv: indica los consumos de los clientes registrados en la empresa.
- users_latam.csv: usuarios de latinoamerica pertenecientes al servicio suministrado por la empresa.
- plans.csv: planes que forman parte de la oferta de ConnectaTel.

## Metodología
- Cargar y explorar
- Identificación de problemas de calidad de datos
- Limpieza básica de datos
- Resúmenes estadísticos de usuarios
- Visualización de distribuciones y outliers
- Segmentación de clientes
- Insight ejecutivo para stakeholders
